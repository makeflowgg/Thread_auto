# Thread Studio

HTML·CSS·JavaScript 화면과 Python 표준 라이브러리 기반 로컬 서버입니다. 현재 버전은 **자동화 운영 화면과 로컬 저장 기반**입니다. 실제 급상승 콘텐츠 수집·AI 분석·영상 렌더링·Threads 게시·자동 댓글은 아직 구현되지 않았습니다. 연결되지 않은 작업을 실행 완료로 표시하지 않습니다.

## 실행

```sh
cd /Users/home/Desktop/Thread_auto
python3 server.py
```

브라우저에서 http://127.0.0.1:8765 에 접속합니다. 종료는 터미널에서 Ctrl+C입니다. 다른 포트는 `python3 server.py --port 8766`으로 지정합니다. 서버는 127.0.0.1에서만 접근할 수 있습니다. HTML 파일을 더블클릭하는 방식은 데이터 저장을 지원하지 않습니다.

## 지금 사용할 수 있는 기능

- 대시보드 숫자 카드 5개, 계정별·상태별 작업 필터, 상세 정보 및 취소.
- 여러 계정의 별도 토큰 입력창. macOS Keychain에 토큰 저장. 공식 Threads `/me` API로 계정 인증 확인. 토큰을 DB·브라우저 저장소·로그에 기록하지 않음.
- 보관 링크·원문 메모 저장, 선택 및 선택 해제.
- 로컬 파일을 OUT으로 가져오기, 영상·사진 미리보기 및 다운로드.
- 영상 `N.mp4`, 해당 사진 `N-N.jpg` 형식. 순번 1–99999, 덮어쓰기 금지, 재시작 후 번호 유지. 사진은 영상 등록 후 작업 번호에 연결. 현재 작업당 영상 1개·사진 1개 지원.
- 비율, 폰트, 크기, 굵기, 최대 글자 수, 상하 여백, 편집·본문·댓글 프롬프트 저장. 배치 예시 미리보기.
- KST 날짜와 00:00–23:00 한 시간 간격의 예약 설정 저장. 본문과 댓글 분리. 본문 URL 검사, 중복 예약 방지, 프리셋 스냅샷 저장.

실행 엔진이 연결되지 않아 새 작업은 **확인 필요** 상태로 저장됩니다. 화면에 저장되는 예약은 아직 실행 예약이 아닙니다. 실제 API 계정 인증은 유효한 사용자 토큰이 필요하며 현재 개발 환경에서는 실계정으로 검증하지 않았습니다. 만료 시 자동 토큰 갱신은 미구현입니다.

## 파일과 인증정보

- `OUT/`: 미디어 파일만 저장. 미디어용 하위 폴더 없음.
- `.data/dashboard.sqlite3`: 계정 표시 이름, 원본 링크, 작업, 프리셋 등 비밀키를 제외한 운영 기록.
- macOS Keychain: 서비스 `ThreadAuto.local.tokens`, 계정별 액세스 토큰.

DB와 OUT은 실행 시 생성되고 Git에서 제외됩니다. 원본 파일은 이동하거나 삭제하지 않고 OUT에 복사합니다. 키체인 권한을 거절하면 토큰 저장은 실패하며 평문 저장으로 우회하지 않습니다. 외부 폰트, 분석 스크립트, CDN을 사용하지 않습니다. 계정 연결 확인 시에만 인증정보를 HTTPS로 공식 `graph.threads.net`에 보냅니다.

## 자동화 완성에 필요한 다음 작업

1. 샤오홍슈 및 Threads 원본 데이터 제공 범위와 사용 가능한 수집 서비스 선정. 실제 조회수 제공 여부 확인 및 시계열 기록으로 급상승 판단.
2. 사용 권한이 있는 원본 미디어를 다운로드하는 수집 어댑터. 원본 자료·상품 매핑·파트너스 URL을 연결하는 데이터 모델.
3. 외부 AI 전송 또는 로컬 분석 방식 결정. 영상·음성·사진 분석과 구조화된 원고 생성. 상품 링크는 등록된 값만 사용.
4. FFmpeg 등 렌더러 연결. 출력 비율·여백, 폰트 실측, 줄바꿈·최소 글자 크기, 장면별 타이밍 처리. 편집 전 원본을 훼손하지 않는 번호 정책 확정.
5. Threads 게시 어댑터와 미디어 전송 방식 구성. 현재 공개 서버는 생성하거나 배포하지 않았음.
6. 영속 실행 큐 및 스케줄러. 콘텐츠 준비는 예약 전에 실행하고, 게시 성공 응답과 게시물 ID를 저장한 뒤 성공 시각 + 15분에 같은 계정으로 댓글 1회. 네트워크 타임아웃 후 실제 게시 여부 재확인으로 중복 방지. 댓글 실패는 게시 재시도와 분리.
7. 앱 종료·컴퓨터 절전·재시작 시 예약 처리 정책, 공식 토큰 갱신, 취소와 재시도 구현. 현재 백그라운드 서비스는 설치하지 않음.

두 입력만으로 자동화하려면 계정별 기본 프리셋뿐 아니라 사용 가능한 상품과 실제 파트너스 링크, 수집 범위가 먼저 설정되어야 합니다. 댓글 위치는 계정 제재를 피할 수 있다는 보장이 아닙니다.

## 검증

```sh
python3 -m unittest discover -s tests -v
node --check web/app.js
```

테스트는 임시 폴더와 메모리 보안 저장소를 사용하며 실제 계정이나 키체인을 수정하지 않습니다.

## 연동 참고

- [Meta 공식 Threads API 컬렉션](https://www.postman.com/meta/threads/documentation/dht3nzz/threads-api): 인증, 미디어 컨테이너, 게시 및 `reply_to_id`.
- 샤오홍슈 급상승 조회수 공개 API 지원 여부는 아직 확인되지 않음. 제3자 서비스를 임의로 연결하지 않았음.
